## [0.1.0] - 2026-08-22

### Added

- Public npm package `vamana` with opt-in Oxlint JS plugins.
- Subpath plugins: `vamana/js`, `vamana/react`, `vamana/base-ui`, `vamana/zod`, `vamana/tanstack-router`, `vamana/elysia`, `vamana/effect`.
- Specifier catalog on the package root (`plugins.js`, `plugins.react`, and the other keys).
- Consumer agent skill under `skills/vamana/`.
